=====================================================
 GRUPO ELYON - Tablero de Gestion
 Como funciona y como se publica
=====================================================

LINK PUBLICO
------------
  https://crleandro-hub.github.io/tablero-elyon/

Repositorio: https://github.com/crleandro-hub/tablero-elyon
GitHub Pages sirve la carpeta docs de la rama main.


=====================================================
 ACTUALIZACION AUTOMATICA (ya configurada)
=====================================================

Una tarea del Programador de tareas de Windows llamada

  "Tablero Elyon - Actualizar y publicar"

corre de lunes a viernes a las 8:30 y ejecuta actualizar_auto.bat,
que hace todo el ciclo:

  1. update_bcra_cache.py   -> TAMAR, BADLAR y UVA (API oficial BCRA)
  2. update_cac_cache.py    -> indice CAC (Excel local de CAMARCO)
  3. build_publicar.py      -> arma docs/index.html y el portable
  4. git add / commit / push -> publica en GitHub Pages

Si la PC estaba apagada a las 8:30, la tarea corre apenas la prendas.
El link publico se refresca 1 o 2 minutos despues del push.

Cada corrida deja constancia en  log_actualizacion.txt  (no se sube
al repo). Si algo falla, la respuesta esta ahi.

Ver o modificar la tarea:  Inicio -> "Programador de tareas"
Reprogramarla desde cero:  doble clic en 3-PROGRAMAR-TAREA-8-30.bat


=====================================================
 ACTUALIZAR A MANO
=====================================================

Doble clic en  2-ACTUALIZAR-TABLERO.bat
(hace lo mismo, pero muestra todo en pantalla y espera un Enter
al final, asi podes leer si algo fallo)


=====================================================
 ARCHIVOS DE LA CARPETA
=====================================================

FUENTE
  tablero_elyon.html            El tablero. Aca se editan los cambios
                                de diseno o de modulos.
  Indicador CAC_serie historica.xls
                                Serie CAC de CAMARCO. Cuando salga un
                                mes nuevo, bajalo de camarco.org.ar
                                /indicadores y pisa este archivo:
                                el resto se actualiza solo.

DATOS (se regeneran solos, no editar a mano)
  bcra_cache.js                 TAMAR, BADLAR, UVA
  cac_cache.js                  Serie CAC completa

SCRIPTS
  update_bcra_cache.py          Baja los datos del BCRA
  update_cac_cache.py           Parsea el Excel del CAC
  build_publicar.py             Embebe los datos en el HTML

SALIDAS (se regeneran solas)
  docs/index.html               Lo que se publica en GitHub Pages
  tablero_elyon_portable.html   Archivo suelto, para mandar por mail
                                o WhatsApp. Anda sin internet, salvo
                                dolar y riesgo pais que son en vivo.

AUTOMATIZACION
  actualizar_auto.bat           Lo ejecuta la tarea de Windows
  2-ACTUALIZAR-TABLERO.bat      Version manual, con pantalla
  3-PROGRAMAR-TAREA-8-30.bat    Crea o recrea la tarea de Windows
  _programar_tarea.ps1          Motor del anterior


=====================================================
 SI ALGO SE ROMPE
=====================================================

"fatal: Unable to create '.git/index.lock': File exists"
  Quedo un bloqueo de una corrida cortada. Se destraba con:

    cd "C:\Users\LMoreno\Dropbox\CLAUDE\Tablero General Grupo Elyon"
    Remove-Item .git\*.lock, .git\objects\maintenance.lock -Force -ErrorAction SilentlyContinue

  actualizar_auto.bat ya hace esta limpieza antes de empezar.

"[EXCEL DESACTUALIZADO]" en el log
  Salio un mes nuevo del CAC. Baja la serie historica de
  camarco.org.ar/indicadores y pisa el .xls de la carpeta.

El push pide usuario y contrasena
  Se perdieron las credenciales del Credential Manager de Windows.
  Corre  git push  a mano una vez desde PowerShell: se abre el
  navegador, autorizas, y queda guardado de nuevo.

El link muestra datos viejos
  Fijate en log_actualizacion.txt si el paso 4 dijo [OK] o [ERROR].
  Tambien puede ser cache del navegador: Ctrl+F5.


=====================================================
 SEGURIDAD
=====================================================

La contrasena del login esta escrita dentro del HTML: cualquiera que
haga "Ver codigo fuente" puede leerla. Sirve como traba casual entre
tu gente, NO como seguridad real.

Hoy el tablero solo muestra indicadores publicos (BCRA, INDEC,
CAMARCO), asi que publicarlo abierto no expone nada sensible.

Cuando sumes los modulos de Ventas y Avance de Obra, hay que pasar a
acceso restringido de verdad (Cloudflare Access con lista de mails
autorizados, o un hosting con login del lado del servidor).
